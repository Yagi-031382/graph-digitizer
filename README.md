# graph-digitizer
文献ごとにスケールや形状が異なる応力–ひずみ曲線を比較するため、PNG/JPEG画像上で指定した点を `(x, y)` の数値データに変換するデスクトップアプリである。曲線の抽出は手動クリック方式である。

## 対象と単位

- x軸：ひずみ [%]。%は元の試料長に対する変形量の百分率であり、`100 × (変形後の長さ − 元の長さ) / 元の長さ`である。
- y軸：応力 [MPa]。MPaは応力の単位であり、`1 MPa = 10^6 N/m²`である。Nは力、m²は面積の単位である。
- 画像座標 `(u, v)` [px]：pxは元画像の画素の位置を表す単位である。左上を原点とし、uは右向き、vは下向きに増加する。
- 軸名と単位は変更できる。単位の換算は行わない。

初版の対象は、x軸が水平、y軸が垂直で、両軸が線形目盛の画像である。対数目盛、画像の傾きや遠近変形の補正、複数曲線の分類には未対応である。非線形の曲線自体は抽出できる。基準点の範囲外も同じ変換式で外挿する。画像の線幅とクリック位置に応じて誤差が生じる。

## セットアップ（Windows 11 / PowerShell）

Python 3.11.9を想定する。以下の各手順では、コマンドを一つずつ実行する。既に取得済みのリポジトリでは手順1を省略する。

1. リポジトリを取得する。
   ```powershell
   git clone https://github.com/Yagi-031382/graph-digitizer.git
   ```
2. リポジトリへ移動する。
   ```powershell
   cd graph-digitizer
   ```
3. 仮想環境を作成する。既に`.venv`が存在する場合は省略する。
   ```powershell
   py -3.11 -m venv .venv
   ```
4. 依存パッケージをインストールする。
   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

仮想環境内のPythonを直接指定するため、Activate.ps1の実行は不要である。VS Codeでのインタープリターには`.venv\Scripts\python.exe`を指定する。パッケージのバージョンはrequirements.txtに固定してある。

## 起動方法

リポジトリ内で実行する。

```powershell
.\.venv\Scripts\python.exe main.py
```

## 操作方法

1. 「画像を開く」を押す。
2. PNGまたはJPEG画像を選択する。
3. x最小の軸値を入力する。
4. x最大の軸値を入力する。
5. y最小の軸値を入力する。
6. y最大の軸値を入力する。
7. 画像上のx軸最小点をクリックする。
8. 画像上のx軸最大点をクリックする。
9. 画像上のy軸最小点をクリックする。
10. 画像上のy軸最大点をクリックする。
11. 曲線上の点を一つクリックする。
12. 必要な点を一つずつ追加する。
13. 右側の表とMatplotlibグラフで値を確認する。
14. 「CSV保存」を押す。
15. 保存先を指定する。

画像読込直後はx軸最小点の指定モードになる。基準点を指定するたびに次のモードへ進み、最後に曲線の取得モードになる。モード欄から指定対象を選び直せる。

基準点は目盛に対応する位置に指定する。例えば、x最小0 %、x最大40 %、y最小0 MPa、y最大5 MPaであれば、その目盛の位置をクリックする。軸名の文字そのものをクリックしない。基準点は同じ原点を共有する必要はない。

ホイール操作で画像を拡大・縮小し、スクロールバーで表示位置を移動できる。「画像全体を表示」で表示倍率を戻す。倍率を変えても元画像の座標で取得する。「最後の点を戻す」で末尾の点を削除できる。表の行を選択して「選択点を削除」を押すと、その点を削除する。

軸の点や値を変更すると取得済みの点も再計算される。基準点が未指定、同じ水平・垂直位置、最大値が最小値以下の場合は、点の追加とCSV保存を拒否する。未保存のデータを持つ状態で画像を変更する場合や終了する場合は破棄を確認する。

## 座標変換

入力は元画像の座標 `(u, v)` [px]、基準点、各基準点に対応する軸値である。出力は軸の単位に従う `(x, y)` である。

```text
x = x_min + (u − u_x_min) / (u_x_max − u_x_min) × (x_max − x_min)
y = y_min + (v − v_y_min) / (v_y_max − v_y_min) × (y_max − y_min)
```

`u_x_min`と`u_x_max`はx軸基準点の水平座標 [px]、`v_y_min`と`v_y_max`はy軸基準点の垂直座標 [px]である。各座標の差の比は無次元である。一般の画像ではy最大点のv座標がy最小点より減少するため、上向きの応力増加をこの式で扱える。

例えばxの基準が100 px→0 %、500 px→40 %、yの基準が400 px→0 MPa、100 px→6 MPaなら、`(300 px, 250 px)`は`(20 %, 3 MPa)`になる。

## CSVと再描画

CSVはUTF-8 BOM付き、列名は`x,y`である。行の順序はクリック順であり、自動で並べ替えない。既定の軸ではx列がひずみ [%]、y列が応力 [MPa]である。単位や校正情報はCSVに含めないため、別の単位を使用する場合はファイル名などで記録する。

Matplotlibは取得した点をクリック順で結ぶ。これはクリックした値の確認用であり、元画像の曲線との一致や文献の測定精度を保証するものではない。

## ファイル構成と関数

| ファイル / 関数 | 入力 | 出力・役割 |
|---|---|---|
| main.py / main | 起動引数 | Qtの終了コード（無次元の整数） |
| calibration.py / Calibration.to_graph | 元画像の座標 [px]、校正情報 | 軸の単位に従う(x, y) |
| calibration.py / Calibration.validate | 保持した基準点と軸値 | 戻り値なし。無効な校正はValueError |
| data.py / make_frame | 点の座標 [px]の一覧、校正情報 | x/yのDataFrame |
| data.py / save_csv | 保存先、点の座標 [px]の一覧、校正情報 | CSVファイル。戻り値なし |
| image_view.py / ImageView | 画像、基準点、取得点 | 画像表示とクリック座標 [px]のシグナル |
| plot_view.py / PlotView.update_plot | x/yのDataFrame、軸名と単位 | Matplotlib描画。戻り値なし |
| app.py / MainWindow | GUI操作 | 校正、取得点、表、保存の管理 |

OpenCVによる半自動抽出を追加する際は、抽出結果を元画像の`(u, v)` [px]の一覧にし、既存の座標変換・CSV出力へ渡せる。初版ではOpenCVで曲線を抽出しない。

## 検証

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

既知の座標の変換、無効な校正の拒否、CSVの値と順序、および画面を表示せずにQtを起動して画像読込・拡大後のクリック・再校正・削除・CSV保存・Matplotlib描画を確認する。GUIテストは`QT_QPA_PLATFORM=offscreen`を使用する。Windows上の画面表示確認は通常の起動コマンドで行う。

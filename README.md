# graph-digitizer
文献ごとにスケールや形状が異なる応力–ひずみ曲線を比較するため、PNG/JPEG画像上の点を `(x, y)` の数値データに変換するデスクトップアプリである。手動クリック取得とOpenCVによる曲線の自動検出に対応する。

## 対象と単位

- x軸：ひずみ [%]。%は元の試料長に対する変形量の百分率であり、`100 × (変形後の長さ − 元の長さ) / 元の長さ`である。
- y軸：応力 [MPa]。MPaは応力の単位であり、`1 MPa = 10^6 N/m²`である。Nは力、m²は面積の単位である。
- 画像座標 `(u, v)` [px]：pxは元画像の画素の位置を表す単位である。左上を原点とし、uは右向き、vは下向きに増加する。
- 軸名と単位は変更できる。単位の換算は行わない。

初版の対象は、x軸が水平、y軸が垂直で、両軸が線形目盛の画像である。対数目盛、画像の傾きや遠近変形の補正、複数曲線の分類には未対応である。非線形の曲線自体は抽出できる。基準点の範囲外も同じ変換式で外挿する。画像の線幅とクリック位置に応じて誤差が生じる。

## セットアップ（Windows 11 / PowerShell）

Python 3.11.9を想定する。以下の各手順では、コマンドを一つずつ実行する。既に取得済みのリポジトリでは手順1を省略する。

1. リポジトリを取得する。
   ```powershell
   git clone https://github.com/Yagi-031382/graph-digitizer.git
   ```
2. リポジトリへ移動する。
   ```powershell
   cd graph-digitizer
   ```
3. 仮想環境を作成する。既に`.venv`が存在する場合は省略する。
   ```powershell
   py -3.11 -m venv .venv
   ```
4. 依存パッケージをインストールする。
   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

仮想環境内のPythonを直接指定するため、Activate.ps1の実行は不要である。VS Codeでのインタープリターには`.venv\Scripts\python.exe`を指定する。パッケージのバージョンはrequirements.txtに固定してある。

## 起動方法

リポジトリ内で実行する。

```powershell
.\.venv\Scripts\python.exe main.py
```

## 操作方法

1. 「画像を開く」を押す。
2. PNGまたはJPEG画像を選択する。
3. x最小の軸値を入力する。
4. x最大の軸値を入力する。
5. y最小の軸値を入力する。
6. y最大の軸値を入力する。
7. 画像上のx軸最小点をクリックする。
8. 画像上のx軸最大点をクリックする。
9. 画像上のy軸最小点をクリックする。
10. 画像上のy軸最大点をクリックする。
11. 曲線上の点を一つクリックする。
12. 必要な点を一つずつ追加する。
13. 右側の表とMatplotlibグラフで値を確認する。
14. 「CSV保存」を押す。
15. 保存先を指定する。

画像読込直後はx軸最小点の指定モードになる。基準点を指定するたびに次のモードへ進み、最後に曲線の取得モードになる。モード欄から指定対象を選び直せる。

基準点は目盛に対応する位置に指定する。例えば、x最小0 %、x最大40 %、y最小0 MPa、y最大5 MPaであれば、その目盛の位置をクリックする。軸名の文字そのものをクリックしない。基準点は同じ原点を共有する必要はない。

ホイール操作で画像を拡大・縮小し、スクロールバーで表示位置を移動できる。「画像全体を表示」で表示倍率を戻す。倍率を変えても元画像の座標で取得する。「最後の点を戻す」で末尾の点を削除できる。表の行を選択して「選択点を削除」を押すと、その点を削除する。

CSV取得モードでは、右下の取得点の表で行を選択すると、右側の再描画グラフで対応する点をオレンジ色で表示する。選択行を変えるとオレンジ色の表示も移動する。選択解除や点の削除で表示を解除する。手動取得・自動取得の両方に対応し、選択操作でCSVの値は変更しない。

軸の点や値を変更すると取得済みの点も再計算される。基準点が未指定、同じ水平・垂直位置、最大値が最小値以下の場合は、点の追加とCSV保存を拒否する。未保存のデータを持つ状態で画像を変更する場合や終了する場合は破棄を確認する。

## 座標変換

入力は元画像の座標 `(u, v)` [px]、基準点、各基準点に対応する軸値である。出力は軸の単位に従う `(x, y)` である。

```text
x = x_min + (u − u_x_min) / (u_x_max − u_x_min) × (x_max − x_min)
y = y_min + (v − v_y_min) / (v_y_max − v_y_min) × (y_max − y_min)
```

`u_x_min`と`u_x_max`はx軸基準点の水平座標 [px]、`v_y_min`と`v_y_max`はy軸基準点の垂直座標 [px]である。各座標の差の比は無次元である。一般の画像ではy最大点のv座標がy最小点より減少するため、上向きの応力増加をこの式で扱える。

例えばxの基準が100 px→0 %、500 px→40 %、yの基準が400 px→0 MPa、100 px→6 MPaなら、`(300 px, 250 px)`は`(20 %, 3 MPa)`になる。

## 曲線の自動取得

画像を読み込み、各軸の最小値・最大値と対応する基準点を指定した後に、「曲線を自動検出」を押す。曲線上の点をクリックする必要はない。候補のうち水平範囲が最も長いものを取得点に反映する。既存の取得点がある場合は、置き換えを確認する。

画像上の取得点と右側の再描画で対象の曲線に一致するか確認する。別の曲線が選ばれている場合は候補欄で選び、「選択候補を取得点に反映」を押す。確認後は従来の「CSV保存」を利用する。複数の候補を個別のCSVに保存できる。軸の基準点または値を変更すると検出候補を破棄するが、取得済みの点は保持して座標を再計算する。

抽出範囲は軸の基準点で囲む矩形である。白背景上の黒・灰色の線、および赤・黄・緑・水色・青・紫の線を対象とする。黒・灰色の線はOtsu閾値で、色の付いた線はHSVの色相と彩度で分離する。画像の軸線を避けるため矩形の境界から3 pxを除外する。pxは元画像の画素の位置・距離を表す単位である。灰色の水平・垂直線が抽出範囲の80 %以上を直線で占める場合はグリッド候補として除去する。80 %は抽出範囲の幅または高さに対する比率である。

「途切れの接続距離」の初期値は12 pxである。同じ色の近接した線分を膨張処理でまとめるためのカーネル幅は「設定値＋1」pxであり、接続の可否は線分の向きと形にも依存する。破線の線分が別々の候補になる場合は値を増やせる。別の線や文字が混ざる場合は値を減らせる。範囲は0～100 pxで、0 pxでは膨張処理を行わない。

まとめた領域の各画像列で、元画像から検出した線の画素の垂直座標の中央値を取得する。元画像に線がない列には点を作らない。出力はx値の昇順で、各列につき1点である。途切れた区間も再描画では端点間を直線で結ぶが、その区間の測定値を復元したことにはならない。

同色の曲線が交差する画像、誤差棒・文字・凡例が曲線に接触する画像、背景に色がある画像、同じx値に複数のy値が対応する曲線では候補が混ざる場合がある。また、水平範囲が最長の候補が目的の曲線とは限らない。軸の境界に重なる線、グリッドと同条件の水平・垂直の曲線も除去される場合がある。元画像と抽出結果を確認する必要がある。手動取得も引き続き利用できる。

## CSVと再描画

CSVはUTF-8 BOM付き、列名は`x,y`である。行の順序はクリック順であり、自動で並べ替えない。既定の軸ではx列がひずみ [%]、y列が応力 [MPa]である。単位や校正情報はCSVに含めないため、別の単位を使用する場合はファイル名などで記録する。

Matplotlibは取得した点をクリック順で結ぶ。これはクリックした値の確認用であり、元画像の曲線との一致や文献の測定精度を保証するものではない。

## CSV描画モード（複数曲線の比較）

「CSV取得」タブは画像からデータを取得するモードである。「CSV描画」タブは保存済みCSVを読み込んで比較するモードである。タブを切り替えても取得点と校正情報は保持する。

1. 「CSV描画」タブを押す。
2. 「CSVを追加（複数選択可）」を押す。
3. 比較するCSVファイルを選択する。
4. ファイル選択画面の「開く」を押す。

CSVは`x,y`列を持ち、各行に有限の数値が必要である。UTF-8またはUTF-8 BOM付きのCSVを読み込める。空のデータ、列の不足、空欄、文字列、NaN、無限大を含むファイルはエラーを表示する。他の有効なファイルは読み込む。

曲線はファイルごとに色分けし、拡張子を含むファイル名を凡例に表示する。同じパスのCSVを再度読み込むと更新し、重複追加はしない。別のフォルダーに同じ名前のCSVがある場合は別の曲線として扱い、凡例には同じ名前が表示される。ファイル一覧の項目にカーソルを置くとフルパスを確認できる。

「点を表示」は初期状態ではOFFであり、線のみを描画する。チェックするとすべての曲線に点を表示し、外すと点を隠す。元のCSVは変更しない。「選択CSVを除外」は選択した曲線を比較図から除外し、CSVファイルは削除しない。

軸名と単位は比較モード内で変更できる。表示名だけの変更であり、数値の換算は行わない。比較前に各CSVの単位とひずみ・応力の定義を確認する必要がある。既定のx単位は%（元の試料長に対する変形量の百分率）、y単位はMPa（応力、1 MPa = 10^6 N/m²）である。

点はCSVの行順で直線で結ぶ。行を並べ替えたり、欠損区間を補間して点を生成したりはしない。途切れた曲線の両端が連続した行にある場合、描画ではその両端を直線で結ぶ。CSVには途切れの情報がないため、その線は欠損区間の測定結果を示さない。

## ファイル構成と関数

| ファイル / 関数 | 入力 | 出力・役割 |
|---|---|---|
| main.py / main | 起動引数 | Qtの終了コード（無次元の整数） |
| calibration.py / Calibration.to_graph | 元画像の座標 [px]、校正情報 | 軸の単位に従う(x, y) |
| calibration.py / Calibration.validate | 保持した基準点と軸値 | 戻り値なし。無効な校正はValueError |
| data.py / make_frame | 点の座標 [px]の一覧、校正情報 | x/yのDataFrame |
| data.py / save_csv | 保存先、点の座標 [px]の一覧、校正情報 | CSVファイル。戻り値なし |
| image_view.py / ImageView | 画像、基準点、取得点 | 画像表示とクリック座標 [px]のシグナル |
| plot_view.py / PlotView.update_plot | x/yのDataFrame、軸名と単位 | Matplotlib描画。戻り値なし |
| plot_view.py / PlotView.compare | ファイル名とDataFrameの組の一覧、軸名と単位、点表示の真偽値 | 色分けした比較図。戻り値なし |
| comparison.py / load_curve | CSVのパス | 数値のx/y列を持つDataFrame。無効なCSVは例外 |
| comparison.py / ComparisonPage.add_csvs | CSVパスの一覧 | 読込エラーの一覧。正常な曲線を追加または更新する |
| extraction.py / extract_curves | uint8のRGB画像、校正情報、接続距離 [px] | 曲線候補の一覧。各候補は元画像の点の座標 [px]を保持する |
| app.py / MainWindow | GUI操作 | 校正、取得点、表、保存の管理 |

OpenCVの抽出結果も元画像の`(u, v)` [px]の一覧として、手動取得と共通の座標変換・CSV出力へ渡す。

